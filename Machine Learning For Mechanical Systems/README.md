## 1. RL Project - PPO-Based Control of an Active Motion Surface for Parcel Singulation

* Course: Machine Learning for Mechanical Systems
  * Professor: Prof. Loris Roveda
* Authors: M. Cigada, M. Davì, S. D'Incà
* Academic Year: 2025 - 2026
* Keywords: Reinforcement Learning, PPO, Active Motion Surface, Parcel Singulation, Continuous Control, Bayesian Optimization, Robustness
* Software used: MATLAB, MATLAB Reinforcement Learning Toolbox
* Goal of the project: Develop and validate a PPO-based controller for a 5 × 5 Active Motion Surface used for parcel singulation. The work includes the formulation and verification of the simulation environment, the definition of a training reward and independent physical KPIs, the tuning of PPO hyperparameters through Bayesian Optimization, and the robustness assessment of the selected policy under non-nominal operating conditions.
* Report: [PPO-Based Control of an Active Motion Surface for Parcel Singulation](MLMS-RL-Project-Report.pdf)
* Presentation PDF: [RL Project Presentation - PDF](RL_Project_Presentation.pdf)
* Presentation PowerPoint: [RL Project Presentation - PPTX](RL_Project_Presentation.pptx)

## 2. Python Project - Surrogate-Assisted Compliant Base-Arm Optimization

* Course: Machine Learning for Mechanical Systems
  * Professor: Prof. Loris Roveda
* Authors: M. Cigada, M. Davì, S. D'Incà
* Academic Year: 2025 - 2026
* Keywords: Neural Network Surrogate, Physics-Informed Neural Network, Bayesian Optimization, Compliant Base, Chirp Excitation, True-EoM Validation, Robustness
* Software used: Python
* Goal of the project: Build a surrogate-assisted optimization workflow for a compliant base-arm mechanical system excited by a chirp command. The work includes dataset generation from the true equations of motion, training and comparison of NN and PINN surrogate models, Bayesian Optimization of the command and arm parameters, true-EoM validation of the selected candidate, and robustness checks with respect to base parameters, arm parameters and initial conditions.
* Report: [Surrogate-Assisted Compliant Base-Arm Optimization](MLMS-PythonProject-Report.pdf)
* Presentation PDF: [Python Project Presentation - PDF](PythonProject_Presentation.pdf)
* Presentation PowerPoint: [Python Project Presentation - PPTX](PythonProject_Presentation.pptx)
